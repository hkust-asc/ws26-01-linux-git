# Week 1 submissions

Place your profile at `submissions/<github-id>/profile.md` and submit it from `submit/<github-id>`. Work only in your own folder unless a quest requires a shared-file change; leave other submissions and `quests/` originals untouched.

Use a preferred name or nickname in your profile and the PR title `[Submit] Preferred Name (@github-id)`; do not include a student ID or legal full name in either. Follow the [submission instructions](../README.md#quest-3-submit-a-profile) to clone the organization repository and try pushing there first; use a fork if that push fails with a 403 because you do not have write access.
